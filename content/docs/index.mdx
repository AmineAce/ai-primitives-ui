## Introduction

**AI Primitives** is a monochrome, Canvas 2D-only orb library for AI interfaces. No WebGL, no motion deps — just `requestAnimationFrame`.

## Quick Start

```tsx title="CloningIndicator.tsx"
import { CloningOrb } from "@ai-primitives-ui/ui";

export function CloningIndicator() {
  return <CloningOrb size={64} aria-label="Cloning repository" />;
}
```

Try all 16 live at `/#playground` — no install needed. Then see [Installation](/docs/installation).
